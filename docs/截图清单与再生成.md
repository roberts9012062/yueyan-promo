### 再生成插件截图

```bash
# 侧边栏四张（首页 / AI / 书签 / 设置）
YUEYAN_API_KEY=oa_xxx bash scripts/capture-extension.sh

# B 站视频总结两张（需人工在弹出窗口扫码登录 B 站，AI 字幕仅登录可见）
YUEYAN_API_KEY=oa_xxx bash scripts/capture-bili.sh
```

脚本逻辑：加载 `boke/dist/browser-extension/` 构建产物（Playwright 有头模式，MV3 扩展不支持无头）→ 经 service worker 写入站点地址与 API Key（存储键 `plugin_settings_v1`）→ 预置演示书签 → 打开侧边栏页面依次截图。

> 依赖说明：复用 `boke/frontend/node_modules` 的 playwright（含浏览器二进制），本仓库不重复安装；截图期间会短暂弹出浏览器窗口。
